### AC2: `pnpm i && pnpm build` 全绿

**字面要求**: pnpm i && pnpm build 全绿

**展开（SM 解释）**:
- 在干净环境（仅安装好 Node 20 LTS、pnpm 9、Go 1.22）下，从仓库根目录依次执行：
  1. `pnpm i`：完成依赖安装，无 ERR/未解析的 peer 依赖（warn 可接受）。
  2. `pnpm build`：触发 Turborepo `build` 任务图，所有现有 workspace 包构建成功；首次运行无缓存，再次运行命中 Turbo cache（FULL TURBO 标识）。
- 至少包含 1 个可构建的占位 TS 包（如 `packages/shared-types/`），用于验证 Turborepo pipeline 实际运行而非空跑。
- `go.work` 至少声明 1 个占位 Go module（如 `apps/api-gateway/` 含最小 `main.go`），`go build ./...` 在 workspace 根可执行成功（Turborepo 不直接编排 Go，但 workspace 文件就位，便于后续 Story 1.5 接入）。
