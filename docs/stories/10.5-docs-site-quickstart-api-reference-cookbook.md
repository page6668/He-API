### AC2: 10 种语言齐全——含阿拉伯文 RTL，切换语言不丢上下文

**Scenario**
```gherkin
GIVEN 文档站已具三大板块（AC1），框架自带或自建 i18n 机制（依 OQ-10.5-1）
  AND locale 集与控制台（10.1）一致：en, zh-CN, ja, ko, es, fr, de, pt, ru, ar（front-end-spec.md:627）
WHEN 用户在任一文档页切换语言
THEN **10 种语言齐全**——三大板块（Quickstart + API Reference + Cookbook）+ SDK 索引在 10 个 locale 下均有对应内容（FR-10.3：可借助机器翻译 + 人工校对，OQ-10.5-4 钉死 MT/校对边界）
  AND 切换语言**停留在当前页对应译文**（不跳回首页、不丢上下文）；URL 含 locale 段（如 `/zh-CN/quickstart`，具体形态依框架）
  AND **阿拉伯文（ar）RTL 正确**：`dir="rtl"`、镜像布局；代码块 / API 路径 / SDK 包名 / 命令等**保持 LTR 孤岛**（不被 RTL 翻转，沿用 10.1 的 LTR-island 范式 `docs/stories/10.1-*.md` BR-10.1.6-8）
  AND 缺译回落到默认语言（en）而非空白/报错（FR-10.3「齐全」+ 10.1 fallback 范式）
  AND 提供**内容完整性 gate**：检测某 locale 缺页/缺板块（对位 10.1 的 `scripts/check-i18n-keys.ts` 思路，文档侧为页面/章节齐全度检查）
```
