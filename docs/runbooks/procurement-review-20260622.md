## 2. 月费对照
| | 现报价单 | 修正后(测试·香港)|
|---|---|---|
| 合计 | **¥4,602.6 / 月**(但跑不起来)| **≈ ¥11,000 – 15,000 / 月** |

> 修正后约为原报价 **2.5–3 倍** —— 因为原单**严重少买了计算(K8s 集群+3节点)并漏了 Redis + 网络/仓库配套**。原报价单字面金额虽低,但**无法部署**。

**预算下限**(够测但偏紧):3×c7.large(2c4g)替代 xlarge + RDS 基础版 + ACR 用共享版 → 可压到 **≈ ¥8,500–10,500 / 月**。

> ⚠️ 上面**不含**两个变量:① 上游 6 家模型 API token 费(过手成本,随调用量)② 公网出口带宽(SSE/多模态出流量)。
