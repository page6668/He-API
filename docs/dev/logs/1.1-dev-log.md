## 偏离/澄清(AC 字面 vs 实现)

**AC2 中 `go build ./...` 在仓库根的字面要求与 Go workspace 实际行为不符:**

- Go 1.22 workspace 模式下,`./...` 通配符要求当前目录有 `go.mod`;
  仓库根没有(根不是 module),会报
  `directory prefix . does not contain modules listed in go.work or their selected dependencies`。
- **等价命令**:`go build ./apps/api-gateway/...` 或 `cd apps/api-gateway && go build ./...`。
- **解决**:提供 `scripts/go-build-all.sh` 脚本,从 `go.work` 解析 `use` 列表后逐 module
  执行 `go build ./...`,真正实现"workspace 内所有 Go module 一键构建"的 AC 意图。
- README 第 "本地启动" 段及"常用命令"表已更新使用此脚本。
- 此偏离不影响 AC2 的业务意图(workspace 全 module 可构建),仅替换了字面命令形态。
