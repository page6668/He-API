## 1. Implementation Summary

Delivers five vendored Helm chart wrappers under `infra/helm/observability/` (`kube-prometheus-stack` / `loki` / `promtail` / `otel-collector` / `jaeger`) — each with `Chart.yaml` + `values.yaml` + `values-staging.yaml` + `README.md`; a Grafana 3-datasource ConfigMap template inside the kube-prometheus-stack wrapper; an OTel Collector ServiceMonitor inside the otel-collector wrapper; five Grafana dashboard JSONs (1 implemented `gateway.json` with 4 OTel-semconv PromQL panels + 4 placeholders) plus a `kustomization.yaml` `configMapGenerator` carrying the `grafana_dashboard: "1"` sidecar label; an `infra/k8s-base/observability-rbac.yaml` adding two ClusterRoles (`prometheus-scraper` + `otel-collector-k8sattrs`) and ClusterRoleBindings; a minimal Go reference service at `apps/sample-otel-app/` (OTel SDK + otelhttp middleware + Prometheus exporter via `promhttp` + structured slog JSON with `trace_id` extracted via `SpanFromContext`) plus its sibling Helm chart at `infra/helm/sample-otel-app/`; a `scripts/observability/install.sh` BOOTSTRAP-MODE script that installs the six releases in Q1 order with the m-3 CRD wait between steps 1 and 2 and M-4 SHA injection at step 6; the `.github/workflows/infra-lint.yml` extension above; and a README "Observability" section anchoring the 5-dashboard contract + operator workflows + cost (+¥0) + Story 1.7+ deferrals.
