## 6. P2a Implementation Summary — password package (Story 2.2 T1.1)

P2a lands the password primitives. The package is dependency-free aside from
`golang.org/x/crypto/bcrypt` and is the single source of truth for bcrypt cost,
HIBP k-anonymity, and length / wipe contracts referenced from every later
handler.

### 6.1 Deliverables

| File | Surface |
|------|---------|
| `apps/auth-svc/internal/password/password.go` | `BcryptCost = 12` (compile-time const). `Hash(pw []byte) ([]byte, error)` — bcrypt cost=12 + `defer wipe(pw)` mutates caller's slice. `Compare(hash, pw []byte) error` — wraps `bcrypt.CompareHashAndPassword`. `ValidateLength(pw []byte) error` — ≥ 10 chars, no class enforcement. `wipe(b []byte)` — package-private zero-fill helper. `ErrPasswordTooShort` exported. |
| `apps/auth-svc/internal/password/hibp.go` | `HIBPClient{BaseURL, HTTPClient}` — injectable for tests. `NewHIBPClient()` — defaults to `https://api.pwnedpasswords.com` + 3 s timeout (TS-CONS-004). `CheckBreached(ctx, pw) error` — sends only `SHA-1(pw)[0:5]` (k-anonymity), fail-closed on transport / 5xx / parse. Returns `ErrPasswordBreached` / `ErrHIBPUnavailable` / nil. `Add-Padding: true` header sent for HIBP response-size defense. |
| `apps/auth-svc/internal/password/password_test.go` | UNIT-001..006 + UNIT-011 + UNIT-012 (8 tests). Memory-wipe asserted by mutating-slice diff. Timing variance test runs 100 match × 100 miss iterations and asserts `|p99_match - p99_miss| < 50ms`. Source-leak scan rejects `fmt.Errorf` / `slog.*` / `errors.New` patterns that interpolate `pw`/`password`/`plaintext`/`cleartext`. |
| `apps/auth-svc/internal/password/hibp_test.go` | UNIT-007..010 (6 tests). httptest stub returns realistic `SUFFIX:COUNT\r\n` body for the breached SHA-1 prefix only. Fail-closed coverage: 500, connection-refused, request timeout, default-timeout-3s. |

### 8.2 Atomicity design choice

QA's UNIT-170 allows either `MULTI/EXEC` or `EVAL`. Implementation picked
Lua-script `EVAL` for two reasons:

1. **Stronger atomicity story.** `MULTI/EXEC` is optimistic (WATCH-based);
   under network partition the EXEC can be aborted. A Lua script runs as a
   single Redis command — no partition between INCR and EXPIRE.
2. **Pod-restart safety.** If auth-svc crashes between `INCR` and `EXPIRE` in
   a pipelined-but-not-bundled command flow, the counter would live forever.
   The Lua script's atomicity removes that failure mode.

miniredis (`gopher-lua` runtime) executes the same script identically to real
Redis, so the unit test exercises the production code path.

### 10.2 Design choices worth noting

- **No SendGrid SDK.** The v3 API is one POST; the official sendgrid-go SDK
  brings in `helpers/mail` builders + transitive deps. A 100-line HTTP
  wrapper is cheaper to maintain, smaller in the distroless image, and
  trivial to mock via `httptest`.
- **Subject as first non-comment line of `.txt`.** Avoids adding a third
  per-locale file just for subjects (10 locales × 3 files would be 30, vs.
  the current 20). Comment-stripping in the parser keeps the `# TODO:
  localize` markers from showing up in the rendered email.
- **Snake_case template vars matching proto.** Templates were PascalCase
  at P1 (`{{.VerificationLink}}`) but the proto `SendEmailRequest.variables`
  uses snake_case keys (`verification_link`) — those have to match for
  `text/template` to resolve the values. Templates realigned to snake_case;
  this is the only path that satisfies the wire contract without a
  case-translation shim.
- **Connect-go error mapping defaults to transient.** An unknown upstream
  error code is treated as retryable rather than permanent — better to
  surface "we couldn't send the email, retry" than to silently drop a
  verification because we couldn't categorize the failure.

### 12.2 URL-segment discrepancy note (QA spec → Next.js convention)

convention, so the physical directory `app/[locale]/(auth)/signup/` serves
at `/<locale>/signup/`, not `/<locale>/(auth)/signup/`.

Implementation follows Next.js. The Server Action redirects to
`/<locale>/signup/check-inbox?email=...`. The vitest UNIT-058 test asserts
the Next-idiomatic URL with a comment pointing back to this note. The
Playwright E2E spec (P6 / QA review) will need a one-line update to drop
the parens from its URL regex — flag for QA.
