### Why "Comprehensive"

Decision 8B locks **Comprehensive** because:

- Rule 1 (Simple) fails: `complexity_indicators = 4 > 0`.
- Rule 2 (Standard) fails: `complexity_indicators = 4 > 2`.
- Rule 3 (Comprehensive) matches: `4 ≥ 3` → unit + integration + e2e mandated; risk profile required.
- Rule 4 (via `security_sensitive`) NOT triggered: `security_sensitive = false`.

Comprehensive adds the **chaos suite** (Toxiproxy 6 REUSE Story-4.1/4.2 + 2 NEW Kimi-specific per T4.3), **contract suite** (`openai==1.40.*` skeleton-only per T4.4), and an **opt-in e2e live suite** (`HE_API_KIMI_LIVE=1` per T4.5 — separate gate from `HE_API_DEEPSEEK_LIVE` AND `HE_API_QWEN_LIVE` so vendor suites run independently per Story Accumulated Context line 740).
