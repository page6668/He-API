**The FOUR HARD gates** (block-merge — a failure on any is a 备案 compliance breach):
- **G1 — 3×3×3 gating matrix** (level × severity × {input, output-nonstream, output-stream}) vs the ratified 8.1 mapping → UNIT-011, UNIT-040.
- **G2 — first-qualifying-hit**: a sub-threshold match must NEVER short-circuit and mask a later qualifying one → UNIT-012, UNIT-020 (≥1 input + ≥1 stream case where `low` precedes `high` under loose/default), UNIT-013.
- **G3 — fail-closed**: `{nil claims, "" field, unknown token} → strict` → UNIT-031, UNIT-033, UNIT-034, UNIT-035, UNIT-042, BLIND-ERROR-001/002.
- **G4 — strict == pre-8.4 byte-identity** on all 3 paths → UNIT-014 (`ScanText==ScanTextMin(_,SeverityLow)`), UNIT-021, UNIT-041.

Detection no-false-negative (the 8.2/8.3 HARD suites) MUST stay green unchanged — **gating is post-detection** → UNIT-043/044. Latency (BENCH-001) is a SOFT gate (`t.Log`-on-fail, mirrors 8.2/8.3 bench precedent).
