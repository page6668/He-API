### Test-Level Interpretation for Security-Sensitive Auth Stories

Story 2.2 is **Epic 2's user-identity starting point** — every downstream Story (2.3 OAuth, 2.4 2FA, 2.5 profile, 2.6 GDPR export, 2.7 deletion, Epic 5 API-key↔user, Epic 7 billing↔user) inherits this Story's `users` table + JWT session model + BFF↔auth-svc path. Test investment is therefore weighted toward **invariants** (bcrypt cost, JWT alg/key-size, cookie attribute matrix, token-hash storage, anti-enumeration timing parity) over implementation details.
