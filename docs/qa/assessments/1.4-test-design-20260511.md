### Test-Level Interpretation for Observability-Stack Stories

Story 1.4 delivers an observability stack (5 vendored Helm charts + 5 dashboard JSONs + a small Go reference service + an RBAC manifest + a one-shot bash bootstrap + a CI workflow extension + README updates). There **is** business runtime code in this story (`apps/sample-otel-app/`), but the bulk of the deliverable is configuration that controls how the stack composes. The pyramid therefore tilts the same way it did for 1.3 (heavily Unit/static), with a small but critical Go-runtime Unit slice for sample-otel-app, plus Integration on the CI surface and E2E on the staging cluster.

| Level | Coverage Strategy |
