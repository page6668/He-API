## Overview

Total: **68** | Unit: 22 (32%) | Integration: 37 (54%) | E2E: 9 (13%)

Test Design Level: **Comprehensive** (Epic-10 directive + **security-sensitive**: new JWT-authed billed gateway endpoint).

### Two test surfaces (full-stack)

This story spans **two languages / two test runners** — the test design assigns each scenario a surface:

| Surface | Where | Runner | Covers |
|---------|-------|--------|--------|
| **GW** = Gateway (Go) | `apps/api-gateway/...` | `go test -race` (httptest / pgxmock per 9.x precedent) | New `POST /v1/me/playground/chat` — JWT fence, `api_key_id` ownership-IDOR, dual-billing, scope-gate, strict-decode, SSE passthrough, error envelope |
| **C-U** = Console unit | `apps/console/__tests__/` | `vitest run` | Export generators, cost-estimate guard, deep-link validation, A/B header assembly, benchmark Zod/SoT, i18n completeness |
| **C-E** = Console e2e | `apps/console/e2e/` | `playwright test` | Page journeys, streaming render, A/B UI, deep-link prefill, public benchmark, ar RTL |

> **Confirmed via repo inspection**: `/v1/me/*` endpoints are gateway Go handlers (`rest-api-spec §5.1.3`; canonical error writer `apps/api-gateway/internal/openaierr.Write`; 9.1/9.2/9.3 per-user IDOR fences). The endpoint is **not** a console BFF route. Front-end E2E uses **mock/intercept** for the billed call — **never burns real quota** (T4.2).

### Architect-mandated focus (Wright `*review 10.6`, OQ rulings)

P0 weighting follows the security-sensitive surface: ① endpoint JWT-`sub` fence; ② `api_key_id` ownership-IDOR; ③ proxied dual-billing (`TPMDeduct`); ④ A/B scope-gate; ⑤ deep-link `#fragment` injection (never `eval`); ⑥ cost = front-end estimate, **never** the money SoT.

## Risk Coverage

No standalone risk-profile was run (security-sensitivity folded into this Comprehensive design). Implicit risk → scenario mapping:

| Risk | Severity | Mitigating scenarios |
|------|----------|----------------------|
| R-IDOR: cross-user billing via forged/foreign `api_key_id` | **Critical** | INT-002, INT-007, BLIND-CONCURRENCY-001 |
| R-BILL: double/incorrect billing on proxied A/B | **Critical** | INT-003, INT-009, INT-012, BLIND-DATA-001 |
| R-INJECT: deep-link `#fragment` arbitrary code execution | **Critical** | UNIT-006, UNIT-007, BLIND-BOUNDARY-004 |
| R-MONEY-SOT: estimate mistaken for billed amount | High | UNIT-005, BLIND-DATA-002 |
| R-SCOPE: A/B leg escapes key scope | High | INT-006, INT-011 |
| R-LEAK: error envelope swallowed / stream half-broken | Medium | INT-014/015/016, BLIND-ERROR-001, BLIND-RESOURCE-001 |
| R-SoT-DRIFT: benchmark hardcodes He pricing | Medium | UNIT-011, BLIND-DATA-003 |
| R-I18N: ar RTL mirrors numerals/ids/code | Low | E2E-005, E2E-007, UNIT-009/013 |
