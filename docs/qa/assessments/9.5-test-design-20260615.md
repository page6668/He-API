**Minimum-coverage check:**
- BOUNDARY per input field — content array (001), image count (002), per-image size (003), body cap (004), base64 payload (005) ✓
- ERROR per external dependency — wire/adapter (E-001), vendor upstream (E-002), upstream usage shape (E-003) ✓
- FLOW per multi-step process — mixed/heterogeneous message handling (F-001) ✓
- CONCURRENCY for security-sensitive shared resource — dedup'd adapter handle (C-001) ✓
- DATA for cross-service op — parts-JSON wire fidelity (D-001) ✓
