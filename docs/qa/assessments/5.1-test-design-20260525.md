### Story-level Scenario-ID convention

- `5.1-UNIT-{NNN}` — Go unit test (testify + table-driven). In-process composition only. Mocks: `pgxmock` for repository (or testcontainers-go PG for integration-flavored unit), `miniredis/v2` for in-memory Redis, `httptest` for gRPC stubs, `bytes.NewReader` for deterministic `crypto/rand` substitution.
- `5.1-INT-{NNN}` — Go integration test. Requires real Postgres 16 (testcontainers-go) AND/OR real Redis 7.2 (testcontainers-go) AND/OR miniKafka (testcontainers-go in KRaft mode). Located in `apps/api-gateway/internal/handlers/me_keys_test.go` (gateway↔auth-svc loop via real binary or in-process composition; tests are parallel-safe via per-test container instances).
- `5.1-E2E-{NNN}` — Real-binary tests in `apps/api-gateway/tests/openai_sdk_keys_e2e_test.py` — pytest 8.* + httpx 0.27.* (Story-3.3 toolchain REUSED); spawns gateway + auth-svc child processes + testcontainers PG + Redis + Kafka; budget ≤ 60s wall-clock per `pytest apps/api-gateway/tests/openai_sdk_keys_e2e_test.py`.
- `5.1-SECURITY-{NNN}` — Security-focused cross-cutting scenarios. May execute at UNIT (TC-9-pattern log-scan) or INTEGRATION level (IDOR matrix). Level annotated per scenario. Mandated by Decision 8B `security_focus=true`.
- `5.1-CACHE-{NNN}` — Cache-coherence scenarios spanning Story-3.2 positive cache + Story-5.1 sentinel; executes at INTEGRATION level (real Redis required to validate `EXISTS` round-trip).
- `5.1-CHAOS-{NNN}` — Resilience scenarios with `toxiproxy` Redis/PG/Kafka chaos; build-tag `chaos` (NOT run in default CI; gated nightly suite per Story-4.x precedent).
- `5.1-BLIND-{CATEGORY}-{NNN}` — blind-spot scenarios tagged `[BLIND-SPOT]` per `blind-spot-categories.yaml`. Categories: BOUNDARY / ERROR / FLOW / CONCURRENCY / DATA / RESOURCE.

Dev MUST embed `// Scenario: {scenario_id}` Go comments at the top of each Go test function (and `# Scenario: {scenario_id}` for Python E2E pytest functions) — `*review 5.1` greps these comments for AC traceability per Story 2.2 / 2.3 / 2.4 / 2.5 / 2.6 / 3.1 / 3.2 / 3.6 / 4.x precedent.
