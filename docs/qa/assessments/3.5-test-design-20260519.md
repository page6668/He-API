### Why "Standard" (not Simple or Comprehensive)

Decision 8B locks **Standard** because:
- Rule 1 (Simple) fails: `complexity_indicators = 2 > 0`.
- Rule 2 (Standard) matches: quality_score=10.0 ≥ 7.0 AND complexity_indicators=2 ≤ 2 AND security_sensitive=false.
- Rule 3 (Comprehensive) fails: requires `complexity_indicators ≥ 3` (Story 3.5 sits at 2 = api_changes + new_patterns).
- Rule 4 (Comprehensive via security_sensitive) NOT triggered: Story 3.5's bearer-auth surface is wholly inherited from Story 3.2; zero new auth/credential/PII paths.

Standard level → no separate risk-profile required (risk-profile is the next-step deepening for `securitySensitive=true` per `core-config.yaml.qa.testDesignThresholds.comprehensive`). The risk surface is enumerated implicitly through ACs (see Risk Coverage table below). One performance regression check (T6.6 cold-start) is borrowed forward from Story 3.1 TC-10 — this is a regression marker, not a Story-3.5-introduced SLO.

### Risk Coverage (Implicit)

|---------------|----------------------|

| **R3 — `BR-1.6` stable-`created` regresses** (handler accidentally recomputes timestamp per request, breaking OpenAI semantics) | 3.5-UNIT-003 (startedAt captured once via counter-stub) + 3.5-INT-005 (two-request handler-level equality) + 3.5-BLIND-CONCURRENCY-001 (100 concurrent calls → identical timestamp) |
| **R4 — `BR-2.4` mock embedding non-determinism** (the public `handlers.GenerateMockEmbedding` API is the Epic 4 contract-test reference — non-determinism here cascades to all adapter contract tests) | 3.5-UNIT-019 (norm ∈ [0.99, 1.01]) + 3.5-UNIT-020 (byte-stable on same input) + 3.5-UNIT-021 (different inputs differ in ≥50% positions) + 3.5-INT-014 (handler-level determinism across two requests) + 3.5-E2E-005 (SDK-level determinism) + 3.5-BLIND-CONCURRENCY-002 (concurrent different inputs → each gets correct vector) + 3.5-BLIND-CONCURRENCY-003 (concurrent same input → all byte-equal) **— triple-layered guard catches generator math / handler-level state leak / network-path nondeterminism** |
| **R5 — `BR-2.7` PII leak via `req.Input` content in slog records** | 3.5-UNIT-023 (slog test double asserts no `slog.Record` attribute contains input bytes — same load-bearing role as Story 3.3 BR-1.8 UNIT-016) |
| **R6 — `BR-2.8` dual-shape parser breaks on edge JSON shapes** (the `json.RawMessage + json.UnmarshalTypeError` fallback is a NEW PATTERN that Epic 9 multimodal will inherit) | 3.5-UNIT-006..012 (table-driven: single / array / empty / nested / null / int) |
| **R7 — Concurrency: package-level `modelsCatalogue` slice mutated by handler** (T1.7 specifies `make + copy` per-request to keep package-level slice immutable; a regression that uses `append` or mutates in-place would silently corrupt subsequent responses) | 3.5-UNIT-019 (DATA-001 — mutating response slice does not affect package-level slice) + 3.5-BLIND-CONCURRENCY-001 (100 concurrent calls; -race clean) |
| **R8 — Bearer-auth chain regresses** (T3.x wiring drops `bearerAuth.RequireAPIKey(...)` wrap) | 3.5-INT-002/003 (models 200/401) + 3.5-INT-012 (embeddings 401) + 3.5-UNIT-004 (defence-in-depth `500_gateway_misconfigured`) — defence-in-depth at handler entry catches the regression even if integration tests are accidentally skipped |
| **R9 — Cold-start SLO regresses** (Story 3.1 TC-10: P95 ≤ 1000ms) | T6.6 (benchmark re-run); not a new scenario, inherited regression check |
