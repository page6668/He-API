# Test Design: Story 6.5 — 路由策略配置 UI（账户级默认路由策略）

2026-06-16 | Turing (QA) | Level: **Comprehensive** (Decision 8B; Epic-6 inheritance + ≥3 complexity indicators + hot-path precedence change + cross-service contract extension)

> Binds the **Architect Round 1 rulings** (2026-06-16, PASS 8.5/10). Where a ruling supersedes an SM default it is marked. Headline: **Q-A = Option B (refined)** — the per-user default is resolved on the chat hot path by a **gateway-side per-user cache read (single Redis GET) + sentinel-based invalidation**, mirroring the Story-7.8 `entitlement.Resolver` seam; the JWT-`drs`-claim path (Option A) is **OVERRULED** (violates the CI-enforced BR-3.6 claim-minimization invariant). All precedence tests are **mechanism-agnostic** (the cascade insertion is independent of the resolution mechanism).

### AC3 — Gateway hot-path: NEW precedence tier + resolution seam + zero regression (Backend, hot path)

> Applicable blind-spots: ALL. The precedence tests (UNIT-016…022) are **mechanism-agnostic**; the resolution-seam tests (UNIT-023…028) exercise the Q-A-ruled cache+sentinel mechanism.

**Precedence cascade — `ParseStrategy` extended to `(model, header, userDefault)`:**

| ID | Lvl | Pri | Test | Why |
|----|-----|-----|------|-----|
| 6.5-UNIT-016 | U | P0 | `default + header` → header wins (user-default ignored) | precedence boundary |
| 6.5-UNIT-017 | U | P0 | `default + meta-model` → meta wins | precedence boundary |
| 6.5-UNIT-018 | U | P0 | concrete model, no header, no meta, `default=cost` → `STRATEGY_COST` | core new behaviour |
| 6.5-UNIT-019 | U | P0 | no default, no header, no meta → `STRATEGY_DEFAULT`, `requestedModel==model` (**BYTE-FOR-BYTE 6.2**) | zero-regression lock — protects the 6-vendor adapter matrix |
| 6.5-UNIT-020 | U | P0 | `meta + header + default` all present → meta wins; `conflict` flag still set (header present) | full cascade order + 6.2 conflict-WARN preserved |
| 6.5-UNIT-021 | U | P1 | enum→Strategy map: quality→QUALITY, cost→COST, latency→LATENCY; none/UNSPECIFIED → tier skipped | mapping correctness |
| 6.5-UNIT-022 | U | P0 | `userDefault=UNSPECIFIED` with header/meta present → identical to 6.2 (additive purity) | BR3-3 — the user-default tier is a pure addition |
