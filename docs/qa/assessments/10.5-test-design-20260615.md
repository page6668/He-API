# Test Design: 10.5 — 文档站（Quickstart + API Reference + Cookbook，10 种语言）

2026-06-15 | Turing (QA) | Level: **Comprehensive** (Epic-10 directive)

## Overview

Total: **36** | Unit: 3 (8%) | Int: 16 (44%) | E2E: 11 (31%) | Blind-Spot: 6 (17%)
Priority: **P0: 15, P1: 13, P2: 8**

**Strategy — shift-left to build-time gates.** This is a presentation-only static docs site (Docusaurus 3.x per Architect OQ-10.5-1). There is almost no runtime business logic, so the bulk of correctness lives in **CI gates** (build, link-check, structural-completeness gate, content-anti-drift cross-checks) — hence the integration-heavy mix. E2E (Playwright, console range) covers the few genuinely user-facing invariants: reachability, public access, language-switch context, and the **highest-risk locale (Arabic RTL + LTR islands)**, which is the only fully human-proofed locale in 10.5 scope.

**Architect rulings honoured in this design:**
- **OQ-10.5-3 anti-drift (binding)** → API Reference ↔ `rest-api-spec.md §5.1` is a P0 CI/review gate (INT-004/005/006), incl. the He-specific `X-He-*` headers and the A/B path where `X-He-Selected-Model` is **NOT** set (`rest-api-spec.md:27`).
- **OQ-10.5-4 completeness-gate severity** → structural gap = **BLOCKING** (INT-012, P0); MT-unproofed locale = **WARNING** (INT-015, P1).
- **OQ-10.5-4 proofing split** → `ar` proofed in-scope → full P0 RTL E2E (E2E-007/008); other 7 MT langs deferred to 10.7 → structural-only smoke (E2E-011, P2).
- **High Issue (10.4 Go SDK = Approved, not Done)** → all Go-SDK content tests are **conditional/`test.skip` until 10.4 reaches Done** (INT-007). Python + TS proceed now (Done on disk).

## Blind Spot Scenarios [BLIND-SPOT]

| ID                        | Category | Pri | Scenario                                                              | Ref          |
| ------------------------- | -------- | --- | -------------------------------------------------------------------- | ------------ |
| 10.5-BLIND-ERROR-001      | ERROR    | P1  | (AC1) A deliberately broken internal link **fails the build gate** (negative test — proves link-check actually blocks) | ERROR-003    |
| 10.5-BLIND-ERROR-002      | ERROR    | P1  | (AC2) Unsupported locale URL (`/zh-TW/quickstart`) → 404 or redirect to default, **no crash/blank** | ERROR-003    |
| 10.5-BLIND-BOUNDARY-001   | BOUNDARY | P1  | (AC2) RTL bidi isolation: Arabic prose with inline LTR token (`chat.completions`) renders without reordering surrounding Arabic | BOUNDARY-005 |
| 10.5-BLIND-FLOW-003       | FLOW     | P1  | (AC2) Direct deep-link into RTL locale (`/ar/api-reference`) renders RTL correctly (no flash of LTR / broken bidi) | FLOW-005     |
| 10.5-BLIND-FLOW-001       | FLOW     | P2  | (AC1) Direct-URL deep link to a section page (SSG) works without client nav | FLOW-005     |
| 10.5-BLIND-FLOW-002       | FLOW     | P2  | (AC2) Switch language then browser-back retains the prior locale page context | FLOW-005     |

**Minimum-coverage check:**
- BOUNDARY: locale-set boundary (UNIT-003), bidi boundary (BLIND-BOUNDARY-001) ✅
- ERROR: external dep is the *build pipeline / link-check* — broken-link build fail (BLIND-ERROR-001) + unsupported-locale (BLIND-ERROR-002) ✅
- FLOW: multi-step = language-switch + deep-link navigation (E2E-009, BLIND-FLOW-001/002/003) ✅
- CONCURRENCY / DATA / RESOURCE: **N/A** — static presentation site, no DB / no concurrent writes / no long-lived resources (documented exclusion, not an omission).
