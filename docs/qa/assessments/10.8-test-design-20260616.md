# Test Design: 10.8

2026-06-16 | Turing (QA)

> **Level: Standard** (post-collapse complexity ~2, `security_sensitive=false`). Story scope ratified to **(b)** — "$5 试用额度" = existing Free-tier monthly entitlement (`MonthlyIncludedCreditUSD:"5.00"` + `MonthlyQuotaUSD:"5.00"`, 7.8), auto-resolved via default-to-free. **No backend money code.** The money-path design (`GrantTrialCredit` / `trial_grants` / `0018` / accumulative credit SQL) is PARKED (Appendix, OUT unless PO overturns OQ-1). Test design therefore omits the money-grant / exactly-once / anti-abuse surface that a (a)-scope would require, and instead **guards the (b) boundary** (no-money-path regression) + verifies existing 7.8 behavior in the Beta composition + ships the AC2 console/docs Beta badge.

## Overview

Total: 20 | Unit: 10 (50%) | Int: 9 (45%) | E2E: 1 (5%) | Blind Spot: 3 (counted within Unit/Int)
Priority: P0: 7, P1: 11, P2: 2

Execution shape: shift-left, guard-heavy. AC1 is largely **verification of existing 7.8 behavior** — several gate scenarios REUSE `apps/api-gateway/internal/featureflag/betamode_test.go` (7.8 UNIT-027/028/029) rather than re-author (duplicate-coverage guard). The 10.8-net-new backend tests are the **composition** (new-verified × beta gate × Free $5) and the **no-money-path boundary guard**. AC2 is genuinely new code (console `BetaBadge` + i18n + checklist step).
