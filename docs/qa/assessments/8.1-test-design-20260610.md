# P0 TRANCHE (execute first — 31 scenarios)

> Priority-by-priority delivery. The P0 set is the security / compliance / construction-invariant core. Every P0 is a **hard gate** at `*review 8.1`. The single defect class that matters most here is the **false-negative** (term that should match but doesn't).

## P0 — AC1: Construction invariants (floors + closed enums + 1:1)

These are the panic-at-construction security invariants (mirrors `plan-catalogue` / `models-catalogue` `NewFromRegistry`).

| ID | Lvl | Pri | Test | Why P0 |
|----|-----|-----|------|--------|
| 8.1-UNIT-001 | U | P0 | `CountByLang()[zh] ≥ 1000` on real corpus | Floor IS the 备案 coverage guarantee; below-floor = under-protection |
| 8.1-UNIT-002 | U | P0 | `CountByLang()[en] ≥ 500` on real corpus | EN floor, same rationale |
| 8.1-UNIT-003 | U | P0 | `NewFromRegistry` **panics** on synthetic zh<1000 registry; msg `safetylexicon: zh term floor not met (got N, need 1000)` | BR-1.1 — must fail the build, never run under-covered |
| 8.1-UNIT-004 | U | P0 | `NewFromRegistry` **panics** on synthetic en<500 registry | BR-1.1 |
| 8.1-UNIT-005 | U | P0 | **panic** on unknown category token; msg `unknown category "<tok>" at <file>:<line>` | BR-1.2 closed enum — an unrecognized class = silent mis-tag |
| 8.1-UNIT-006 | U | P0 | **panic** on unknown severity token | BR-1.3 — severity feeds 8.4 per-Key strictness |
| 8.1-UNIT-007 | U | P0 | 1:1 term→metadata enforced — no term without metadata, no metadata orphan | BR-1 invariant — an orphan = an unmatchable / untagged rule |

## P0 — AC2: Normalization (false-negative prevention — the gravest defect class)

`Normalize` is a pure function → unit. The **same** entrypoint is mandated for 8.2/8.3 query inputs (BR-2.2), so a bug here propagates to every consumer.

| ID | Lvl | Pri | Test | Why P0 |
|----|-----|-----|------|--------|
| 8.1-UNIT-008 | U | P0 | `Normalize`: NFKC full-width→half (`Ｂａｄ` → `bad`) | Width-evasion would bypass the filter |
| 8.1-UNIT-009 | U | P0 | `Normalize`: ASCII case-fold (`BADWORD` → `badword`); Chinese unaffected | Case-evasion bypass |
| 8.1-UNIT-010 | U | P0 | `Normalize`: strip zero-width `U+200B/200C/200D/FEFF` | Zero-width insertion is a known evasion |
| 8.1-UNIT-011 | U | P0 | `Normalize`: trim surrounding ASCII + Unicode whitespace | Padding evasion |
| 8.1-UNIT-012 | U | P0 | `Normalize`: composite ordered pipeline `  Ｂａｄ​Word  ` → `badword` (AC2 example) | Proves the FIXED order NFKC→fold→trim→zw (BR-2.2) |
| 8.1-UNIT-013 | U | P0 | Equivalence class: `Lookup("BADWORD")` and `Lookup("ｂａｄword")` resolve to the **same** canonical entry | The producer/consumer shared-normalization contract |

## P0 — AC2: Construction validation (dedupe + empty + length cap)

| ID | Lvl | Pri | Test | Why P0 |
|----|-----|-----|------|--------|
| 8.1-UNIT-014 | U | P0 | cross-**category** duplicate term → **panic** naming both `fileA:lnA & fileB:lnB` | BR-2.3 — silent dedupe forbidden (corpus must stay auditable) |
| 8.1-UNIT-015 | U | P0 | cross-**language** duplicate term → **panic** | BR-2.3 — dedupe is GLOBAL across langs |
| 8.1-UNIT-016 | U | P0 | term normalizing to empty → **panic** `term at <file>:<line> normalizes to empty` | Corrupt data must fail the build, not store a phantom |

## P0 — AC3: Matching API (no-false-negative + authoritative lookup + concurrency)

| ID | Lvl | Pri | Test | Why P0 |
|----|-----|-----|------|--------|
| 8.1-UNIT-018 | U | P0 | **Exhaustive** no-false-negative: ∀ stored term, `Lookup(t).ok ⇒ MightContain(t)==true` | BR-3.1 — a Bloom **false-negative** = a missed filter = compliance failure (THE security invariant) |
