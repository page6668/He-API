## Overview

Total: **78** | Unit: 49 (63%) | Int: 21 (27%) | E2E: 8 (10%)

Project type: **fullstack** (api-gateway Go + notification-svc Go + analytics-svc Go + console Next/TS).
All blind-spot categories apply (BOUNDARY, ERROR, FLOW, CONCURRENCY, DATA, RESOURCE).

### P0 elevation list (Architect-directed — the security spine of this story)
1. **IDOR per-user isolation** — user_id from JWT `sub` only; worker dump fenced `WHERE user_id=?`; user B never in A's dump.
2. **PII + cost exclusion** — projection = EXACTLY the 13 BR-RD-9 columns (grep-auditable allow-list); no `client_ip`/`client_country`/`user_agent`/`error_message`/`cost_usd`.
3. **Signed-URL non-leak** (TS-CONS-008) — never logged, never in `failure_reason`, never rendered in console DOM; email-only delivery.
4. **CSV formula-injection escape** (OWASP `= + - @ \t \r`) + RFC-4180 validity.
5. **Cross-kind isolation** (the EXTEND regression surface) — usage-log export never appears in 2.6 GDPR `/current` and vice-versa.
6. **Double-consume / idempotency** — Kafka at-least-once + claim-guard; one export → one OSS object → one email.
