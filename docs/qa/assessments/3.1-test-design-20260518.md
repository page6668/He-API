2026-05-18 | Turing (QA) | Level: **Comprehensive** | Risk-profile: **NOT REQUIRED** (security_sensitive=false; AC2 cold-start gate is a perf-budget, not a security risk)

### Story-level Scenario-ID convention

- `3.1-UNIT-{NNN}` — Go (testify) unit test; pure-logic, no external I/O (uses `httptest.NewRecorder` + `httptest.NewRequest` per existing handlers/ convention)
- `3.1-INT-{NNN}` — Go integration test; in-process composition via `httptest.NewServer(rootMux)` OR child-process spawning via `exec.Command` (cold-start path)
- `3.1-E2E-{NNN}` — Real-process tests; the cold-start runner actually `exec.Command`s a CGO=0 production binary on `127.0.0.1:8080` and polls `/health` — this IS the E2E surface for this story
- `3.1-BLIND-{CATEGORY}-{NNN}` — blind-spot scenarios tagged `[BLIND-SPOT]` per `blind-spot-categories.yaml`

Dev MUST embed `// Scenario: {scenario_id}` Go comments at the top of each test function — `*review 3.1` greps these comments for AC traceability per Story 2.2 / 2.3 / 2.4 / 2.5 / 2.6 precedent.

### Project-type detection

Backend Go monolith app (`apps/api-gateway`) — single binary, stdlib `net/http.ServeMux` (Go 1.22 method-aware) + `connectrpc/connect 1.16+`. Tests are colocated `*_test.go` files inside the same package (Go convention; matches existing handlers/me_test.go / jwks_test.go layout established by Stories 2.2 – 2.6).

High-priority blind-spot categories per `applicability.backend_api`: **BOUNDARY, ERROR, CONCURRENCY, DATA, RESOURCE**; medium: **FLOW**. `security_sensitive=false`, so no auto-priority elevation.

### Architect Round 1 ruling impact on test design

- **MJ-1** (CI build-flag mismatch; SM adopts Option (c) per Wright's recommendation → new BR-2.9): `3.1-INT-020`, `3.1-INT-021` assert that `TestColdStart` shells out to `exec.Command("go", "build", "-trimpath", "-ldflags=-s -w", "-o", binPath, "./cmd/server")` with `CGO_ENABLED=0` forced in env (overriding any inherited CI CGO=1 + `-race` from `unit-go` job).
- **MJ-2** (AC3 grep scope expansion → 5 additional doc files; load-bearing perf §10 5k-QPS claim): `3.1-UNIT-040` runs the expanded `grep -rn 'Fiber\|fiber\|fasthttp' docs/` (no subdir restriction); `3.1-UNIT-046` through `3.1-UNIT-050` enumerate the 5 stragglers explicitly. `3.1-UNIT-048` asserts the perf §10 rewrite includes the "stdlib net/http: P95 ≤ 100 ms observed in Story 3.1 cold-start; sustained-QPS benchmark deferred to Epic 9 k6 baseline" annotation per MJ-2 Recommendation (a).
- **mn-1** (drop new `HE_API_OTEL_DISABLED` env var; use empty `OTEL_EXPORTER_OTLP_ENDPOINT`): `3.1-INT-023` asserts `TestMain` runs `os.Unsetenv("OTEL_EXPORTER_OTLP_ENDPOINT")` and the existing `TestNewTracerProvider_EmptyEndpointFallback` no-op path is exercised — no parallel kill-switch env var introduced.
- **mn-2** (5-run P95 is statistically degenerate → bump to 10): `3.1-INT-022` runs 10 iterations; `runs` const = 10; `3.1-UNIT-020` validates the percentile helper with 10-element fixtures.
