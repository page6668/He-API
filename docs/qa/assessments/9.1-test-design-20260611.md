## Scenarios by AC

### AC1: 调用日志摄取管道 — gateway emits `request.logged` on every terminal outcome → analytics-svc → ClickHouse `request_logs` (+ hourly_agg MV)

| ID | Lvl | Pri | Test | Why level |
|----|-----|-----|------|-----------|
| 9.1-INT-003 | I | P0 | Migration 002 round-trip: `up` creates `request_logs` (MergeTree, `PARTITION BY toYYYYMM(ts)`, `ORDER BY (user_id,ts,he_request_id)`, `TTL 90 DAY`) + MV **WITH `success_count`, WITHOUT `avg/p95`** (H-2); `down` drops MV then table | DDL contract + reversibility; testcontainers |
| 9.1-UNIT-001 | U | P0 | Terminal success (200) emits ONE event: status_code=200, token triple, latency split, cost from `X-He-Cost-Usd` | Pure producer logic |
| 9.1-UNIT-002 | U | P0 | Each error class (402/403/429/502/504/400_content_filter/5xx) emits ONE event: right status_code+error_code, tokens=0-where-none — the 成功率 rows `usage.recorded` misses | Branch logic |
| 9.1-UNIT-003 | U | P0 | Fire-and-forget `[BLIND-SPOT: ERROR-002]`: Kafka down → WARN+drop; 200/error body byte-identical to pre-9.1; never delays/mutates response | Isolated guarantee |
| 9.1-UNIT-004 | U | P0 | PII discipline: NO message content, NO completion text, NO plaintext key in event | Compliance |
| 9.1-UNIT-005 | U | P0 | `cost_usd` NON-NULL DEFAULT 0 `[BLIND-SPOT: BOUNDARY-001]`: pre-dispatch 402 emits 0 (not null); negative→0+WARN (H-1) | Money integrity |
| 9.1-INT-001 | I | P0 | Consumer reads `request.logged` → row in `request_logs`; hourly_agg MV auto-populates (request_count, success_count, token sums, cost) | Component interaction; testcontainers CH+Kafka |
| 9.1-INT-002 | I | P0 | Aggregation correctness `[BLIND-SPOT: DATA-002]`: `sum(success_count)/sum(request_count)` over MV == `countIf(status<400)/count()` over raw, across month/quarter (seeded) | OLAP merge semantics |
| 9.1-UNIT-008 | U | P1 | A/B request (6.4) emits ONE event, `model`=served-leg (Q-AB) | Branch logic |
| 9.1-UNIT-009 | U | P1 | Batched writer buffers + flushes on size AND time threshold `[BLIND-SPOT: RESOURCE-001]` | Writer logic |
| 9.1-UNIT-010 | U | P1 | Named-column INSERT: `selected_by_strategy` written (H-3); `team_id`/`user_agent`/`error_message` → column defaults | Writer mapping |
| 9.1-UNIT-011 | U | P1 | Field clamps `[BLIND-SPOT: BOUNDARY-005]`: status_code out-of-range → clamp+WARN; negative tokens → 0+WARN | Validation |
| 9.1-INT-006 | I | P1 | Malformed event → `request.logged.dlq`, partition NOT blocked `[BLIND-SPOT: ERROR-003]` | Pipeline resilience |
| 9.1-INT-007 | I | P1 | Duplicate delivery within Q-DEDUP tolerance (≪0.01%); MergeTree unchanged `[BLIND-SPOT: CONCURRENCY-002]` | At-least-once behavior |
| 9.1-INT-008 | I | P1 | ClickHouse down on consumer → retry+backoff, offset NOT committed → redelivery on recovery `[BLIND-SPOT: ERROR-002]` | Consumer resilience |

## Risk Coverage

No formal `risk-profile` artifact exists for 9.1 (security_sensitive=false; security_focus=false). The dominant risks the suite addresses:

| Risk | Mitigated by |
|------|--------------|
| Cross-user data leak (IDOR) — CRITICAL | 9.1-INT-005 (P0), 9.1-E2E-001 (P0) |
| 成功率 wrong (failed requests not logged) | 9.1-UNIT-002 (P0), 9.1-INT-002 (P0) |
| Ingestion breaks the core API latency/availability | 9.1-UNIT-003 (P0 fire-and-forget) |
| PII leak via analytics event / read endpoint | 9.1-UNIT-004 (P0), 9.1-INT-015 (P1) |
| Money mis-serialization (float / null cost) | 9.1-UNIT-005, 9.1-UNIT-007 (P0) |
| Broken MV math (avg/p95 in SummingMergeTree) | 9.1-INT-003 (P0 — asserts avg/p95 absent) |
| Wrong period boundaries (timezone) | 9.1-INT-009 (P1) |
