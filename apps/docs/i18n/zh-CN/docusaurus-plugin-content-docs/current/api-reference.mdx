# API 参考

He-API 在 `/v1/*` 下提供**兼容 OpenAI** 的 HTTP 接口面。base URL 为
`https://api.he-api.com/v1`。使用 bearer token 鉴权：

```
Authorization: Bearer he-xxxxxxxxxxxxxxxxxxxxxxxxxxxx
```

:::info 事实源
本页转录自 `docs/architecture/rest-api-spec.md` **§5.1**（权威契约）。网关兼容 OpenAI，并带有
少量 He 特有的扩展，文中将逐处标注。
:::

## 端点

| 方法 | 路径 | 用途 |
|--------|------|---------|
| `POST` | `/v1/chat/completions` | 对话补全（非流式与 SSE 流式）。 |
| `POST` | `/v1/embeddings` | 文本嵌入。 |
| `POST` | `/v1/audio/transcriptions` | 语音转文字（Whisper 兼容）。 |
| `POST` | `/v1/audio/speech` | 文字转语音（TTS）。 |
| `GET`  | `/v1/models` | 模型列表 + 能力矩阵。 |
| `GET`  | `/v1/usage` | 本月用量（`?currency=usd|rmb`）。 |
| `GET`  | `/v1/balance` | 账户余额（`?currency=usd|rmb`）。 |

## POST /v1/chat/completions

创建对话补全。请求与响应报文遵循 OpenAI 格式。

```
POST /v1/chat/completions
Authorization: Bearer he-xxxxxxxxxxxxxxxxxxxxxxxxxxxx
Content-Type: application/json
Accept: application/json   (or text/event-stream for SSE)

Optional headers:
  X-He-Routing-Strategy: quality | cost | latency
  X-He-AB-Models: qwen-max,deepseek-v3   # A/B dual-leg compare (non-streaming only)
  Accept-Language: en                    # locale for error messages
```

**请求体**（与 OpenAI 一致）：

```json
{
  "model": "qwen-max",
  "messages": [{ "role": "user", "content": "Hello" }],
  "stream": false,
  "temperature": 0.7,
  "max_tokens": 2048,
  "tools": [],
  "tool_choice": "auto",
  "response_format": { "type": "json_object" }
}
```

`model` 可为具体模型 id（`qwen-max`、`deepseek-v3` 等），也可为路由别名
（`he-router-cost`、`he-router-quality` 等）。

**响应**（成功，非流式）：

```json
{
  "id": "chatcmpl-xxx",
  "object": "chat.completion",
  "created": 1715000000,
  "model": "qwen-max",
  "choices": [],
  "usage": { "prompt_tokens": 100, "completion_tokens": 200, "total_tokens": 300 }
}
```

### 流式（SSE）

当请求体设置 `"stream": true` 时，响应为 `text/event-stream`。每个事件为
`data: <single-line JSON>\n\n`；流以 OpenAI 迭代器哨兵 `data: [DONE]` 结束：

```text
Content-Type: text/event-stream; charset=utf-8
Cache-Control: no-cache, no-transform

data: {"id":"chatcmpl-...","object":"chat.completion.chunk","choices":[{"index":0,"delta":{"role":"assistant"},"finish_reason":null}]}

data: {"id":"chatcmpl-...","object":"chat.completion.chunk","choices":[{"index":0,"delta":{"content":"Hello "},"finish_reason":null}]}

data: {"id":"chatcmpl-...","object":"chat.completion.chunk","choices":[{"index":0,"delta":{},"finish_reason":"stop"}]}

data: [DONE]
```

`object` 为字面量 `chat.completion.chunk`；`delta` 在首个 chunk 携带 `{"role":"assistant"}`，
内容 chunk 携带 `{"content":"..."}`，终止 chunk 携带 `{}`；`finish_reason` 在终止 chunk 之前
为 `null`，之后为 `"stop"`。

### A/B 对比（X-He-AB-Models） {#ab-compare-x-he-ab-models}
发送 `X-He-AB-Models: modelA,modelB`（恰好两个互异的具体 id，**仅非流式**）会并行派发两个模型，
并在一个 `chat.completion` 中返回两者输出。`choices[]` 数组先是 A 路的 choices，随后是 B 路的，
重新编号为 `0,1,…`，每个 choice 携带附加的 `x_he_model` 字段标明来源 leg；`usage` 为成功 leg 的
token 之和。

:::caution A/B 路径上的 X-He-Selected-Model
在 A/B 路径上，响应头 `X-He-AB-Models` 回显已服务的 id，而
**`X-He-Selected-Model` is NOT set**。若恰有一个 leg 失败，响应仍为 `200`，并带一个失败 leg 标记
choice（`finish_reason: "he_upstream_error"`）；仅成功 leg 计费。若两个 leg 均失败，返回单个终态错误
envelope（任一 leg 超时则 504，否则 502）。
:::

## POST /v1/embeddings

创建文本嵌入。请求与响应兼容 OpenAI。

```json
{ "model": "text-embedding-v3", "input": "The quick brown fox" }
```

## POST /v1/audio/transcriptions

语音转文字（Whisper 兼容）。`multipart/form-data`，包含音频 `file` 与 `model`。

## POST /v1/audio/speech

文字转语音。针对给定的 `model`、`input` 与 `voice` 返回二进制音频。

## GET /v1/models

返回模型列表及每个模型的能力矩阵。`/public/models` 提供一个公开、免鉴权的镜像（字节同型）。

## GET /v1/usage 与 GET /v1/balance

查询本月用量与当前余额。两者均接受 `?currency=usd|rmb`（默认 `usd`；其它值 →
`400_unsupported_currency`）。币种换算**仅用于展示**——计费账本始终以 USD 记录。

## 响应头

每个对话补全响应都携带以下响应头：

| 响应头 | 含义 |
|--------|---------|
| `X-He-Request-Id` | 请求关联 id（`req_xxxxxxxxxxxx`）——联系客服时请提供。 |
| `X-He-Selected-Model` | 实际路由到的模型。**在 A/B 路径上不设置**（见上文）。 |
| `X-He-Cost-Usd` | 本次请求的消费（USD）。 |

---

## 错误码

每个错误响应都携带规范的 5 字段 envelope：

```json
{
  "error": {
    "code": "402_quota_exhausted",
    "message": "Insufficient quota.",
    "type": "invalid_request_error",
    "param": null,
    "he_request_id": "req_xxxxxxxxxxxx"
  }
}
```

`type` 对 4xx 码为 `invalid_request_error`，对 5xx 码为 `server_error`。

| HTTP | `error.code` | 含义 |
|------|--------------|---------|
| 400 | `400_invalid_request` | 参数非法。 |
| 400 | `400_content_filter` | 命中内容安全过滤。 |
| 400 | `400_unsupported_currency` | `?currency=` 不在 `{usd, rmb}`。 |
| 401 | `401_invalid_api_key` | Key 无效或被吊销。 |
| 402 | `402_balance_insufficient` | 余额不足。 |
| 402 | `402_quota_exhausted` | 月度上限熔断。 |
| 403 | `403_ip_not_whitelisted` | 调用方 IP 不在该 key 的白名单中。 |
| 403 | `403_model_not_in_scope` | Key 无权调用该模型。 |
| 413 | `413_payload_too_large` | 请求体超出 1 MiB 限制。 |
| 429 | `429_rate_limit_qps` | 每秒请求数超限。 |
| 429 | `429_rate_limit_rpm` | 每分钟请求数超限。 |
| 429 | `429_rate_limit_tpm` | 每分钟上游 token 数超限。 |
| 500 | `500_internal_error` | 系统异常。 |
| 502 | `502_upstream_unavailable` | 上游模型不可用（failover 重试耗尽后）。 |
| 504 | `504_upstream_timeout` | 上游模型超时（failover 重试耗尽后）。 |
