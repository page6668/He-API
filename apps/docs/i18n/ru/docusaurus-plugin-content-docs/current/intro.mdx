# He-API

**He-API** — это OpenAI-совместимый шлюз LLM. Направьте свой существующий код OpenAI на
He-API, изменив всего одну вещь — `base_url` — и получите доступ ко множеству вышестоящих моделей
через единый API-ключ, с маршрутизацией, учётом использования и биллингом, выполняемыми за вас.

```python
from openai import OpenAI

client = OpenAI(
    base_url="https://api.he-api.com/v1",   # the only change
    api_key="he-xxxxxxxxxxxxxxxxxxxxxxxxxxxx",
)
```

## С чего начать

- **[Быстрый старт](/quickstart)** — заставьте первый вызов `chat.completions` работать менее чем за 5 минут.

- **[Сборник рецептов](/cookbook)** — ориентированные на задачи рецепты для копирования и вставки: потоковая передача, поиск через эмбеддинги, аудио, маршрутизация / A-B, использование.
- **[SDK](/sdk)** — официальные drop-in SDK для Python, TypeScript и Go.

## Что вы получаете

- **Drop-in совместимость.** Конечные точки `/v1/chat/completions`, `/v1/embeddings`, `/v1/audio/*`
  и `/v1/models` соответствуют проводному формату OpenAI, поэтому существующие SDK и инструменты работают без изменений.
- **Один ключ, множество моделей.** Вызывайте конкретные модели (`qwen-max`, `deepseek-v3`, …) или
  позвольте стратегии маршрутизации выбрать за вас (`he-router-quality`, `he-router-cost`).
- **Встроенный учёт и биллинг.** Каждый ответ несёт `X-He-Request-Id`,
  `X-He-Selected-Model` и `X-He-Cost-Usd`, так что вы можете отслеживать и учитывать расходы.
