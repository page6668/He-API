# Démarrage rapide

Passez de zéro à votre première réponse de modèle en **moins de 5 minutes**. Vous allez vous inscrire,
créer une clé API et effectuer un appel `chat.completions` avec le SDK de votre choix.

## 1. S'inscrire et créer une clé API

1. Inscrivez-vous sur **[console.he-api.com](https://console.he-api.com)**.
2. Ouvrez **API Keys** et cliquez sur **Create key**.
3. Copiez la clé — elle ressemble à `he-xxxxxxxxxxxxxxxxxxxxxxxxxxxx`. Vous ne pourrez plus la revoir.

Stockez la clé dans une variable d'environnement afin qu'elle ne se retrouve jamais dans le contrôle de version :

```bash
export HE_API_KEY="he-xxxxxxxxxxxxxxxxxxxxxxxxxxxx"
```

:::note URL de base et identifiants
L'URL de base de la passerelle est `https://api.he-api.com/v1`. He-API s'authentifie avec la
variable d'environnement **`HE_API_KEY`** (les SDK officiels ne lisent **pas** `OPENAI_API_KEY`).
:::

## 3. Effectuer votre premier appel

<Tabs groupId="sdk">
  <TabItem value="python" label="Python">

```python
from he_api import Client

client = Client()  # reads base_url + HE_API_KEY from the environment

resp = client.chat.completions.create(
    model="qwen-max",
    messages=[{"role": "user", "content": "Say hello in one sentence."}],
)
print(resp.choices[0].message.content)
```

  </TabItem>
  <TabItem value="typescript" label="TypeScript">

```typescript
import { Client } from "@he-api/sdk";

const client = new Client(); // baseURL + HE_API_KEY from the environment

const resp = await client.chat.completions.create({
  model: "qwen-max",
  messages: [{ role: "user", content: "Say hello in one sentence." }],
});
console.log(resp.choices[0].message.content);
```

  </TabItem>

## Migration depuis OpenAI {#migrating-from-openai}
He-API est compatible OpenAI, donc migrer une application existante est un **changement de `base_url` avec
zéro modification de code** sur vos sites d'appel. Avec le SDK officiel OpenAI, définissez l'URL de base et la clé :

```python
from openai import OpenAI

client = OpenAI(
    base_url="https://api.he-api.com/v1",   # the only change
    api_key="he-xxxxxxxxxxxxxxxxxxxxxxxxxxxx",
)
# every client.chat.completions / client.embeddings call now flows through He-API
```

Préférez les [SDK He-API](/sdk) lorsque vous souhaitez que les valeurs par défaut de la passerelle (URL de base + `HE_API_KEY`)
et les fonctionnalités spécifiques à la passerelle (stratégies de routage, comparaison A/B) soient câblées pour vous.
