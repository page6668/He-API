# Inicio rápido

Pasa de cero a tu primera respuesta de modelo en **menos de 5 minutos**. Te registrarás,
crearás una clave de API y harás una llamada a `chat.completions` con el SDK de tu elección.

## 1. Regístrate y crea una clave de API

1. Regístrate en **[console.he-api.com](https://console.he-api.com)**.
2. Abre **API Keys** y haz clic en **Create key**.
3. Copia la clave — tiene un aspecto como `he-xxxxxxxxxxxxxxxxxxxxxxxxxxxx`. No podrás volver a verla.

Guarda la clave en una variable de entorno para que nunca acabe en el control de versiones:

```bash
export HE_API_KEY="he-xxxxxxxxxxxxxxxxxxxxxxxxxxxx"
```

:::note URL base y credenciales
La URL base de la pasarela es `https://api.he-api.com/v1`. He-API se autentica con la
variable de entorno **`HE_API_KEY`** (los SDKs oficiales **no** leen `OPENAI_API_KEY`).
:::

## 3. Haz tu primera llamada

<Tabs groupId="sdk">
  <TabItem value="python" label="Python">

```python
from he_api import Client

client = Client()  # reads base_url + HE_API_KEY from the environment

resp = client.chat.completions.create(
    model="qwen-max",
    messages=[{"role": "user", "content": "Say hello in one sentence."}],
)
print(resp.choices[0].message.content)
```

  </TabItem>
  <TabItem value="typescript" label="TypeScript">

```typescript
import { Client } from "@he-api/sdk";

const client = new Client(); // baseURL + HE_API_KEY from the environment

const resp = await client.chat.completions.create({
  model: "qwen-max",
  messages: [{ role: "user", content: "Say hello in one sentence." }],
});
console.log(resp.choices[0].message.content);
```

  </TabItem>

## Migrar desde OpenAI {#migrating-from-openai}
He-API es compatible con OpenAI, por lo que migrar una aplicación existente es un **cambio de `base_url` con
cero cambios de código** en tus puntos de llamada. Con el SDK oficial de OpenAI, establece la URL base y la clave:

```python
from openai import OpenAI

client = OpenAI(
    base_url="https://api.he-api.com/v1",   # the only change
    api_key="he-xxxxxxxxxxxxxxxxxxxxxxxxxxxx",
)
# every client.chat.completions / client.embeddings call now flows through He-API
```

Prefiere los [SDKs de He-API](/sdk) cuando quieras los valores predeterminados de la pasarela (URL base + `HE_API_KEY`)
y las funciones específicas de la pasarela (estrategias de enrutamiento, comparación A/B) ya conectadas por ti.
