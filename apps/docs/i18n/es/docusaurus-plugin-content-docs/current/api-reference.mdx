# Referencia de la API

He-API expone una superficie HTTP **compatible con OpenAI** bajo `/v1/*`. La URL base es
`https://api.he-api.com/v1`. Autentícate con un token bearer:

```
Authorization: Bearer he-xxxxxxxxxxxxxxxxxxxxxxxxxxxx
```

:::info Fuente de la verdad
Esta página está transcrita de `docs/architecture/rest-api-spec.md` **§5.1** (el contrato
canónico). La pasarela es *compatible* con OpenAI con algunas adiciones específicas de He, indicadas en línea.
:::

## Endpoints

| Método | Ruta | Propósito |
|--------|------|-----------|
| `POST` | `/v1/chat/completions` | Chat completions (sin streaming y streaming SSE). |
| `POST` | `/v1/embeddings` | Embeddings de texto. |
| `POST` | `/v1/audio/transcriptions` | Voz a texto (compatible con Whisper). |
| `POST` | `/v1/audio/speech` | Texto a voz (TTS). |
| `GET`  | `/v1/models` | Lista modelos + matriz de capacidades. |
| `GET`  | `/v1/usage` | Uso de este mes (`?currency=usd|rmb`). |
| `GET`  | `/v1/balance` | Saldo de la cuenta (`?currency=usd|rmb`). |

## POST /v1/chat/completions

Crea un chat completion. Los cuerpos de solicitud y respuesta coinciden con el formato de OpenAI.

```
POST /v1/chat/completions
Authorization: Bearer he-xxxxxxxxxxxxxxxxxxxxxxxxxxxx
Content-Type: application/json
Accept: application/json   (or text/event-stream for SSE)

Optional headers:
  X-He-Routing-Strategy: quality | cost | latency
  X-He-AB-Models: qwen-max,deepseek-v3   # A/B dual-leg compare (non-streaming only)
  Accept-Language: en                    # locale for error messages
```

**Cuerpo de la solicitud** (igual que OpenAI):

```json
{
  "model": "qwen-max",
  "messages": [{ "role": "user", "content": "Hello" }],
  "stream": false,
  "temperature": 0.7,
  "max_tokens": 2048,
  "tools": [],
  "tool_choice": "auto",
  "response_format": { "type": "json_object" }
}
```

`model` puede ser un id de modelo concreto (`qwen-max`, `deepseek-v3`, …) o un alias de enrutador
(`he-router-cost`, `he-router-quality`, …).

**Respuesta** (éxito, sin streaming):

```json
{
  "id": "chatcmpl-xxx",
  "object": "chat.completion",
  "created": 1715000000,
  "model": "qwen-max",
  "choices": [],
  "usage": { "prompt_tokens": 100, "completion_tokens": 200, "total_tokens": 300 }
}
```

### Streaming (SSE)

Cuando el cuerpo de la solicitud establece `"stream": true`, la respuesta es `text/event-stream`. Cada
evento es `data: <single-line JSON>\n\n`; el stream termina con el centinela del iterador de OpenAI
`data: [DONE]`:

```text
Content-Type: text/event-stream; charset=utf-8
Cache-Control: no-cache, no-transform

data: {"id":"chatcmpl-...","object":"chat.completion.chunk","choices":[{"index":0,"delta":{"role":"assistant"},"finish_reason":null}]}

data: {"id":"chatcmpl-...","object":"chat.completion.chunk","choices":[{"index":0,"delta":{"content":"Hello "},"finish_reason":null}]}

data: {"id":"chatcmpl-...","object":"chat.completion.chunk","choices":[{"index":0,"delta":{},"finish_reason":"stop"}]}

data: [DONE]
```

`object` es el literal `chat.completion.chunk`; `delta` lleva `{"role":"assistant"}` en
el primer chunk, `{"content":"..."}` en los chunks de contenido y `{}` en el chunk terminal;
`finish_reason` es `null` hasta el chunk terminal, luego `"stop"`.

### Comparación A/B (X-He-AB-Models) {#ab-compare-x-he-ab-models}
Enviar `X-He-AB-Models: modelA,modelB` (exactamente dos ids concretos distintos, **solo sin
streaming**) despacha ambos modelos en paralelo y devuelve ambas salidas en un solo
`chat.completion`. El arreglo `choices[]` son las choices de la rama A seguidas de las de la rama B, reindexadas
`0,1,…`, cada una con un campo aditivo `x_he_model` que nombra su rama de origen; `usage` es la
suma de tokens de las ramas exitosas.

:::caution X-He-Selected-Model en la ruta A/B
En la ruta A/B la cabecera de respuesta `X-He-AB-Models` repite los ids servidos, y
**`X-He-Selected-Model` is NOT set**. Si exactamente una rama falla, la respuesta sigue siendo `200`
con una choice marcadora de rama fallida (`finish_reason: "he_upstream_error"`); solo se facturan las ramas
exitosas. Si ambas ramas fallan, se devuelve un único envelope de error terminal (504 si alguna rama
expiró por tiempo, si no 502).
:::

## POST /v1/embeddings

Crea embeddings de texto. Solicitud y respuesta compatibles con OpenAI.

```json
{ "model": "text-embedding-v3", "input": "The quick brown fox" }
```

## POST /v1/audio/transcriptions

Voz a texto (compatible con Whisper). `multipart/form-data` con un `file` de audio y un `model`.

## POST /v1/audio/speech

Texto a voz. Devuelve audio binario para el `model`, `input` y `voice` dados.

## GET /v1/models

Devuelve la lista de modelos más una matriz de capacidades por modelo. Hay disponible un espejo público y
sin autenticación en `/public/models` (forma idéntica byte a byte).

## GET /v1/usage & GET /v1/balance

Consulta el uso de este mes y el saldo actual. Ambos aceptan `?currency=usd|rmb` (predeterminado
`usd`; cualquier otro valor → `400_unsupported_currency`). La conversión de moneda es **solo para visualización** —
el libro mayor de facturación siempre está en USD.

## Cabeceras de respuesta

Cada respuesta de chat completion lleva estas cabeceras:

| Cabecera | Significado |
|----------|-------------|
| `X-He-Request-Id` | Id de correlación de la solicitud (`req_xxxxxxxxxxxx`) — cítalo para soporte. |
| `X-He-Selected-Model` | El modelo al que se enrutó realmente. **Not set on the A/B path** (ver arriba). |
| `X-He-Cost-Usd` | Costo de esta solicitud en USD. |

## Códigos de error

Cada respuesta de error lleva el envelope canónico de 5 campos:

```json
{
  "error": {
    "code": "402_quota_exhausted",
    "message": "Insufficient quota.",
    "type": "invalid_request_error",
    "param": null,
    "he_request_id": "req_xxxxxxxxxxxx"
  }
}
```

`type` es `invalid_request_error` para los códigos 4xx y `server_error` para los códigos 5xx.

| HTTP | `error.code` | Significado |
|------|--------------|-------------|
| 400 | `400_invalid_request` | Parámetros mal formados. |
| 400 | `400_content_filter` | Activó el filtro de seguridad de contenido. |
| 400 | `400_unsupported_currency` | `?currency=` no está en `{usd, rmb}`. |
| 401 | `401_invalid_api_key` | Clave inválida o revocada. |
| 402 | `402_balance_insufficient` | Saldo de la cuenta demasiado bajo. |
| 402 | `402_quota_exhausted` | Se alcanzó el tope de gasto mensual. |
| 403 | `403_ip_not_whitelisted` | La IP del llamante no está en la lista de permitidos de la clave. |
| 403 | `403_model_not_in_scope` | La clave no está autorizada para el modelo solicitado. |
| 413 | `413_payload_too_large` | El cuerpo de la solicitud excede el límite de 1 MiB. |
| 429 | `429_rate_limit_qps` | Se superó el límite de solicitudes por segundo. |
| 429 | `429_rate_limit_rpm` | Se superó el límite de solicitudes por minuto. |
| 429 | `429_rate_limit_tpm` | Se superó el límite de tokens upstream por minuto. |
| 500 | `500_internal_error` | Error inesperado del servidor. |
| 502 | `502_upstream_unavailable` | Modelo upstream no disponible (tras reintentos de failover). |
| 504 | `504_upstream_timeout` | El modelo upstream expiró por tiempo (tras reintentos de failover). |
