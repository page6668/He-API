# 빠른 시작

제로에서 첫 모델 응답까지 **5분 이내**에 도달하세요. 회원 가입을 하고,
API 키를 생성한 다음, 원하는 SDK로 `chat.completions` 호출을 수행하게 됩니다.

## 1. 회원 가입 및 API 키 생성

1. **[console.he-api.com](https://console.he-api.com)**에서 가입하세요.
2. **API Keys**를 열고 **Create key**를 클릭하세요.
3. 키를 복사하세요 — `he-xxxxxxxxxxxxxxxxxxxxxxxxxxxx` 형태입니다. 다시 볼 수 없습니다.

키가 소스 관리에 절대 들어가지 않도록 환경 변수에 저장하세요:

```bash
export HE_API_KEY="he-xxxxxxxxxxxxxxxxxxxxxxxxxxxx"
```

:::note Base URL & credentials
게이트웨이 기본 URL은 `https://api.he-api.com/v1`입니다. He-API는
**`HE_API_KEY`** 환경 변수로 인증합니다(공식 SDK는 `OPENAI_API_KEY`를 읽지 **않습니다**).
:::

## 3. 첫 호출 수행

<Tabs groupId="sdk">
  <TabItem value="python" label="Python">

```python
from he_api import Client

client = Client()  # reads base_url + HE_API_KEY from the environment

resp = client.chat.completions.create(
    model="qwen-max",
    messages=[{"role": "user", "content": "Say hello in one sentence."}],
)
print(resp.choices[0].message.content)
```

  </TabItem>
  <TabItem value="typescript" label="TypeScript">

```typescript
import { Client } from "@he-api/sdk";

const client = new Client(); // baseURL + HE_API_KEY from the environment

const resp = await client.chat.completions.create({
  model: "qwen-max",
  messages: [{ role: "user", content: "Say hello in one sentence." }],
});
console.log(resp.choices[0].message.content);
```

  </TabItem>

## OpenAI에서 마이그레이션 {#migrating-from-openai}
He-API는 OpenAI 호환이므로 기존 앱 마이그레이션은 호출 지점에 대한 **코드 변경 없이
`base_url`만 변경**하면 됩니다. 공식 OpenAI SDK에서 기본 URL과 키를 설정하세요:

```python
from openai import OpenAI

client = OpenAI(
    base_url="https://api.he-api.com/v1",   # the only change
    api_key="he-xxxxxxxxxxxxxxxxxxxxxxxxxxxx",
)
# every client.chat.completions / client.embeddings call now flows through He-API
```

게이트웨이 기본값(기본 URL + `HE_API_KEY`)과 게이트웨이 전용 기능(라우팅 전략, A/B 비교)이
미리 연결되기를 원한다면 [He-API SDK](/sdk)를 선호하세요.
